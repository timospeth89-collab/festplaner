# festplaner

Cockpit des Festplaners zum Jubiläum 100 Jahre Sportfreunde Schneeberg 1928 e. V. (2.–5. Juni 2028).

Diese Seite enthält keine Daten. Nach der Anmeldung mit einem Vereinskonto liest und schreibt sie die
Planungs-Excel im Team „Veranstaltungen“ und den Plan „Festplan 100 Jahre“ in Microsoft Planner.

Veröffentlicht über GitHub Pages aus dem Branch `gh-pages`. Die Quelle der Seite liegt im privaten
Repository `SPFR-1928-Liegenschaften` unter `Fest2028/web/index.html`.
